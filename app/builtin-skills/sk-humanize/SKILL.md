# 去 AI 味与文风模仿

## 为什么需要这一步

模型写的稿子有几个**一眼能认出来**的毛病：

- 段末总要总结一句（「心中充满了对未来的向往。」）
- 「仿佛整个世界都安静下来」这类**空转的比喻**，删掉不影响情节
- 每个动作都配一个副词（缓缓、微微、轻轻、静静）
- 对白说完还要加一句解释
- 形容词成堆（「复杂、纠结、难以言喻」）

这些不是文笔差，是**没有取舍**——每一句都想写好，结果每一句都没信息。

## 第一步：逐条删，不改写

先把下面这些**整句删掉**，删完再看剩下的：

- 段末的总结句、感慨句、展望句
- 「仿佛…」「似乎…」「好像…」后面那半句比喻
- 只起承接作用的过渡句（「而这一切，才刚刚开始」）
- 对白后面解释人物心情的那半句
- 重复上一句信息量的句子

⚠ 删到一半会发现某些段只剩两句。那就**把两句合进上一段**，不要留一个孤零零的短段。

## 第二步：把词换实

| AI 腔 | 换成 |
|---|---|
| 缓缓地 | 直接做（动作本身就是慢的） |
| 微微皱眉 | 皱眉 |
| 眼神中闪过一丝 | 看了他一眼 / 没有看他 |
| 心中充满了 | 删掉，直接写他做了什么 |
| 复杂、纠结、难以言喻 | 写清楚是哪一件事难办 |
| 仿佛整个世界都安静下来 | 删 |

⚠ **「缓缓 / 微微 / 轻轻 / 静静 / 淡淡」每段最多留一个**，而且只有真的需要那个慢时才留。

## 第三步：标点逐句查

⚠ 这是最容易被忽略、而读者一眼就看出来的地方：

- 对白必须用 `「」`，**成对**。出现 `“…”“…` 这种一个开一个关的，一律改。
- 不用省略号 `……` 收尾（除非真的没说完）。不用 `——` 破折号转折。
- 一段里不要同时出现 `「」` 与 `“”`。
- 问句用 `？`，不用 `?`；顿号用 `、`，逗号用 `，`，全角。

## 第四步：模仿文风（用户给了范本时）

1. **先读三遍**用户给的范本，只记三件事：
   - 句子平均多长
   - 视角是贴身的还是拉远的
   - 段落多长、有没有单句成段
2. **抄结构，不抄词**。把范本的段落骨架套到新内容上，
   但不要用范本里的任何具体比喻、句式或意象 —— 抄了就是 plagiarism。
3. **写完对比**：把新写的和范本并排放，看句长节奏像不像。
   不像就再调一遍句长，比调词管用。

## 完成后自查

- [ ] 有没有段末总结句
- [ ] 有没有 `仿佛 / 似乎 / 好像` 开头的比喻
- [ ] 「缓缓/微微/轻轻」是不是超了一个
- [ ] 对白的 `「」` 是不是都成对
- [ ] 有没有「心中充满了」这类空情绪
- [ ] 删完之后字数掉得太多吗（掉一半说明删狠了，回头补细节而不是补废话）

## 不要做的事

- 不要把「去 AI 味」做成**换同义词**。那样只是把套路词换了一套，节奏还是 AI 的。
- 不要为了「像人」而加错别字、口语碎片、网络梗 —— 那是另一种假。
- 不要动情节、名字、设定。**只动表达。**
