# 写对白

对白写得好不好，看三件事：**认得出是谁在说话**、**推进了关系或信息**、**贴合当下处境**。

## 工作流程

### Step 1：先确认在场的两个人是谁

对白写不像话，九成是人物身份没搞清。
先看 `设定/人物库.md` 里有没有「说话方式」这一项：

- 简短还是啰嗦
- 爱用反问还是陈述
- 有没有口头禅
- 什么身份（对长辈和对晚辈，说话方式不一样）

人物库里没写说话方式，就照最近几章的语感推断，别自己另立一套。

### Step 2：写对白的硬性约束

- **用「」包裹**，不用引号、不用破折号代替
- **单句不超过 40 字**：对白太长读者会走神，也说明人物在"演讲"而不是在说话
- **不写"他说"这类解释性转述**，也不在台词后加括号注释动作
  （要动作就把动作另起一行，夹在两句台词之间）
- **不写大段内心独白**，除非用户明确要

### Step 3：检查功能

写完自查，这段对白做到了吗：

1. **认得出人**：遮住人名，能从说话方式认出是谁吗
2. **有推进**：去掉某一句，信息或关系有损失吗。没有就删
3. **贴处境**：这个人在这种场合会说这个吗

## 示例

```
不好：
「你终于来了。」他说，「我等了你很久了，我知道你一定是被
那些事情耽搁了，不过没关系，现在你来了就好。」

好：
「等很久了。」他把茶推过去，没看她，「凉了就别喝了。」
```

区别不在字数，在**后者没有一句是在解释自己**。
