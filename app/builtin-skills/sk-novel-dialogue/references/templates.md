# 人物「说话方式」字段怎么写

> 这个字段是对白质量的关键。人物库里没写它，模型只能凭最近几章的语感猜，
> 猜出来的结果通常是"所有人说话一个味"。

## 字段格式

在 `设定/人物库.md` 的每个角色下面加：

```markdown
### [角色名]
- **身份**：
- **说话方式**：
```

## 怎么写这一条

不要写形容词（"说话很冷"），要写**可观察的习惯**。

| 不要这样写 | 这样写 |
|---|---|
| 说话很冷 | 句子短，从不用"我觉得"。别人问三句才答一句 |
| 性格温和 | 习惯先应一声"嗯"再说话，从不打断别人 |
| 老成持重 | 爱用反问，喜欢说"你想想" |
| 脾气火爆 | 一句话里常夹两个感叹号，骂人先骂娘 |
| 沉默寡言 | 全章说话不超过三句，其余用动作表达 |

**判断标准**：照这条写出来的话，遮住人名能认出是谁吗？
认不出就还不够具体。

## 至少覆盖这三类

写长篇时，最容易崩的是这几组对话，建议每组都至少给主要角色写一条：

1. **主角**（决定全书的语感基调）
2. **与主角对话最多的那个角色**（对手或搭档）
3. **不同辈分或身份的人**（让读者听得出身份差异）

## 对话场景速查

写对白时，按场景调一下习惯的用法：

| 场景 | 提示 |
|---|---|
| 正式场合 | 身份低的人句子更短、更常用敬语；不要让所有人都口语化 |
| 生死关头 | 越紧张越短。人在逃命时不会说完整的因果句 |
| 久别重逢 | 允许有一句没说完的话，比千言万语更真 |
| 隐藏身份 | 说出来的和想说的要不一样——读者能感觉到别扭才有效 |

## 对照示例

```
人物库里的写法（不够具体）：
  沈砚：说话简练

照此写出来的对白：
  「你来晚了。」
  「嗯。」
  「事情办完了。」
  「办得如何？」
  「成了。」

问题：认不出是谁，换成任何人都成立。

补足后的写法：
  沈砚：说话简练，从不用敬语。跟长辈说话也硬邦邦的，
        被问急了会用一句反问顶回去。

写出来的对白：
  「你来晚了。」
  「路远。」
  「路远。」沈砚看了他一眼，「所以呢？」
```

区别在于：**"用反问顶回去"是可复现的行为，而"简练"不是。**
