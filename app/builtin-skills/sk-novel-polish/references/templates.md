# 润色的边界：什么算润色，什么算改情节

> 判据只有一条：**改完之后，除了语言，别的什么都没变。**

## 算润色（语言层）

| 改动 | 例子 |
|---|---|
| 删修饰词 | 「极其美丽的夜色」→「夜色」 |
| 拆长句 | 三个分句叠一句 → 拆成三句 |
| 换更具体的词 | 「很生气」→「他把茶盏墩在桌上」 |
| 统一称谓 | 一段里"他/少年/师兄"混用 → 统一 |
| 删解释性的话 | 动作已经说清了，后面又补一句说明 → 删掉说明 |

## 不算润色（越界了）

| 改动 | 为什么越界 |
|---|---|
| 加一个动作 | 改变了角色的行为，不是语言问题 |
| 改台词的意思 | 对白是情节的一部分，改它就改了情节 |
| 删掉一段心理描写 | 那是内容，不是语言 |
| 换掉一个形容词来"更有画面感" | 如果原词承担了设定含义，换掉就改了设定 |
| 调整段落顺序 | 改变了叙事节奏 |

## 三个自查问题

拿不准的时候，问自己：

1. **这句话改了吗？** —— 改了就不是润色，交给「章节修订」
2. **主角这一章做的还是同一件事吗？** —— 不是就说明动了情节
3. **有没有出现设定里没有的东西？** —— 有就是越界了，即使读起来更顺

## 用户明确说了什么

以下情况**不算越界**，因为是用户要求的：

- "这段太啰嗦" → 就是要你删，删到不啰嗦为止
- "把形容词去掉" → 就是让你删修饰词
- "改得口语化一些" → 就是改语言

判据是**用户要什么**，不是"润色必须保持什么"。

## 交付时怎么说

不用逐句汇报。用户要的是改好的段落。

简短说明方向即可：

> 砍掉了三处形容词，拆了两个长句，把"很生气"换成了动作。情节和对话一个字没动。

比逐条列二十个改动有用。
