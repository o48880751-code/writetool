# 长篇结构：模板

> 这些表写在 `卷纲/` 目录下，一个项目一套。
> 文件名就用下面的标题，不要另起一套命名 —— 名字固定，模型下次才找得到。

## 一、卷纲（`卷纲/第N卷-卷名.md`）

```markdown
# 第N卷 · 卷名

## 卷末目标（一句话）
这一卷结束时必须发生的事：

## 卷末代价（必填）
谁失去了什么（死亡 / 背叛 / 断念 / 失势）：

## 倒推链
| 顺位 | 前置事件 | 需要的筹码 | 筹码来源 | 代价 |
|---|---|---|---|---|
| 4（最近） | | | | |
| 3 | | | | |
| 2 | | | | |
| 1（卷首） | | | | |

> 从"卷末"往上填：4 是紧挨卷末的那一步，1 是卷首起点。
> 每一行的"代价"不能是空的 —— 白来的筹码会让结局变轻。

## 阶段节点
### 阶段一（第 1~4 章）· 目标
- 转折：
- 结束后主角的处境：

### 阶段二（第 5~9 章）· 目标
- 转折：
- 结束后主角的处境：

（按实际阶段数继续）

## 章节钩子
| 章 | 一句钩子（读者看完还想知道什么） | 服务的阶段 |
|---|---|---|
| 1 | | |
| 2 | | |

⚠ 钩子写"事件"是无效的。反例：「夜枫打败了对手」。
正例：「他赢了，但那把刀认了对面为主」。
```

|---|---|---|---|---|

## 矛盾
| A | B | 矛盾点 | 当前状态 | 可能引爆的章节 |

## 四、伏笔回收对照表（`卷纲/伏笔回收表.md`）

```markdown
# 伏笔回收对照表

| 编号 | 埋于 | 内容 | 计划回收 | 实际回收 | 状态 |
|---|---|---|---|---|---|
| F001 | 第3章 | 墨染袖口的血纹 | 第40章左右 | | 未收 |

状态只有三种：未收 / 已收 / **弃收（写明为什么）**。
⚠ "弃收"是合法的，但必须写理由 —— 允许放弃，不允许忘记。
```

## 六、牺牲代价清单（`卷纲/牺牲代价.md`）

```markdown
# 牺牲代价清单

| 角色 | 死于 | 换来了什么 | 铺垫章节 | 是否足够 |
|---|---|---|---|---|
| | 第N章 | 情报/觉悟/局势/某人转变 | | 够/不够→推后 |

⚠ "铺垫章节"是空的，说明读者还不认识他 —— 这时候让他死，只是数字。
⚠ "换来了什么"填不出来的，**删掉这次死亡**，换个方式制造压力。
```

## 七、境界/力量体系表（`卷纲/力量体系.md`）

```markdown
# 力量体系

| 境界 | 能做到 | **做不到**（必填） | 突破代价 | 当前有此境界的人 |
|---|---|---|---|---|

⚠ "做不到"这一列是防膨胀的核心。
只写上界不写下界的体系，三卷之内一定失控。
⚠ 同境界的人数要数得过来。满地都是，压迫感就没了。
```

## 填写顺序建议

1. 先写**卷末目标 + 卷末代价**（这两行定了，整卷才有方向）
2. 再倒推四到六步（倒推链）
3. 再切阶段
4. 最后才拆章节钩子 —— 钩子是阶段的产物，不是拍脑袋想出来的

反过来（先想章节再拼阶段）会得到一卷"每章都热闹、合起来不知道在讲什么"的东西。
