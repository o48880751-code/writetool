# 长篇结构工程

长篇崩掉的原因通常不是文笔，是**结构**：写到第三卷发现没东西可写、
反派越换越强、埋的伏笔忘了收、势力关系乱成一团。

这个技能只解决结构问题。**文学上的要求（母题、人物、克制、纪律）
在「写新章节」的创作准则里，这里不重复，但每一条都同样适用。**

## 输出顺序（固定，不要调换）

**核心主旨 → 人物底层设定 → 世界观与社会规则 → 逆推分卷大纲（含阶段节点）→ 配套附表**

先说清主旨，再定人，再铺世界，再往回推大纲，最后补表。
顺序反了会写出"世界观很热闹但不知道在讲什么"的东西。

## 一、逆推：先定终点，再往回铺

⚠ **不要顺推**（"接下来发生什么"）。顺推出来的大纲会越写越散，
因为每一步都在为下一步找理由，而不是为一个结局铺路。

逆推五问，逐层往下：

1. **这一卷结束时，必须发生什么？** 一句话说完，不许写"经历了很多"。
2. **代价是什么？** 谁死了、谁背叛了、主角失去了什么。
   一卷结束时**没有任何损失**，说明这一卷可以整卷删掉。
3. **要让这件事发生，前面必须已经有什么？** —— 这就是前置事件。
4. **每件事需要什么筹码？** 人、物、情报、身份、人情、把柄。
5. **筹码从哪来、谁给的、代价是什么？** 白来的筹码会让结局失去重量。

推到**卷首状态**，停下来检查：它和上一卷的结尾接得上吗？
接不上，说明中间缺了一层，补在卷首而不是硬圆。

## 二、层级：卷 → 阶段 → 章节钩子

| 层级 | 规模 | 一个单元只做一件事 |
|---|---|---|
| 卷 | 10~30 章 | 一个目标 + 一个代价 |
| 阶段 | 3~5 章 | 一个转折（认知变、关系变、局势变） |
| 章节钩子 | 1 章 | 这一章结束时读者**还想知道什么** |

⚠ 钩子不是"这一章发生了什么"，是"读者看完会追问什么"。
写成事件摘要的钩子是无效的。

拆完对照检查：**每个阶段都在为卷末那个代价服务吗？**
有阶段删掉不影响卷末，那它就是水章，合并进相邻阶段。

## 三、世界观的底层社会逻辑

写势力之前先回答四个问题，答不上来这个势力就是空壳：

- **钱从哪来**：税、商路、矿、香火、保护费
- **粮从哪来**：产粮区在哪、运输线经过谁的地盘、仓储归谁
- **人从哪来**：招募、世袭、流民、买
- **谁在中间赚差价**：商队、镖局、行会、牙人

**市井是独立力量，不是背景板**：商会、镖局、码头、赌坊、青楼、药铺——
它们不站队，只看利弊。主角要办事，绕不开这些中间人。

**势力内部至少一条裂痕**：主战/主和、老派/新派、嫡/庶、清流/浊流。
没有裂痕的势力是铁板，铁板只能被外力打碎，写不出博弈。

**博弈要写推演过程，不只写结果**：
他为什么这么选？他怕什么？他如果不选会怎样？
只写"某某输了"，读者不知道输在哪，也记不住赢了谁。

## 四、反派分层与牺牲代价清单

| 层级 | 作用 | 出场跨度 |
|---|---|---|
| 小反派 | 制造压力、把规则演示给读者看 | 3~10 章 |
| 中反派 | 逼主角**改变做法**（不是单纯变强） | 一卷 |
| 终局反派 | 与核心母题正面冲突 —— 他是主角另一种可能的答案 | 全书 |

**牺牲代价清单（必填）**：每死一个有名有姓的角色，记三件事：

1. 死的是谁、在第几章
2. **换来了什么**：情报、觉悟、局势变化、某人的转变
3. 换不来东西的，**别让他死**

⚠ 这条和第 5 条禁令是一对：死人不是不行，是**不能白死**。

## 五、配套附表（结构的地基）

四张表，写在 `卷纲/` 下，格式见 `references/templates.md`：

- **时间年表**：纪年 / 事件 / 涉及势力 / 与主线的关系
- **势力矛盾表**：A vs B / 矛盾点 / 当前状态 / 可能引爆的章节
- **伏笔回收对照表**：埋于第几章 / 内容 / 计划回收章节 / 状态
- **专有名词索引**：名 / 类型 / 首次出现 / 一句话说明

**力量体系保持克制**：每加一层境界，必须同时写清**这一层做不到什么**。
只有上限、没有代价的体系，三卷之内必然膨胀到没法写。

## 六、四条禁令（比上面五节更重要）

1. **不为加剧情新增组织、门派、猎奇设定。**
   新势力出现的唯一理由是"现有势力解决不了这个问题"，不是"这里需要一个反派"。
2. **不为反转而反转。** 每个反转先问：它改变了谁的什么？
   答不上来就是纯意外，删掉。反转必须服务人物弧光或核心母题。
3. **不堆无关支线。** 支线只有两种合法身份：服务主线，或完成某个人物的弧光。
   两者都不占的，砍。
4. **不批量生成功能性工具人。** 有名字的角色至少有一个**自己的目的**；
   没有目的的，要么不给他名字，要么别让他出场。

## 与写正文的衔接

大纲产出后，写正文时用「写新章节」技能。
它会读 `章节摘要.md` 与设定库，本章场景与实体白名单仍以那边为准。

附表不是写完就扔——每写完一章，回到这里更新**伏笔回收对照表**与**时间年表**。
